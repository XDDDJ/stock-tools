## 详细行业说明

### 消费/IP/娱乐（泡泡玛特、迪士尼类）
- **特点**：轻资产、高毛利，IP 生命周期驱动增长
- **乐观情景**：主力 IP 延续强势 + 新 IP 矩阵爆发 + 海外加速
- **基准情景**：主力 IP 热度缓降，新 IP 部分接力，增速放缓
- **悲观情景**：主力 IP 衰退，新 IP 不及预期，估值体系切换

### 科技/SaaS（群核科技、Salesforce 类）
- **特点**：高增长、高研发投入，规模效应驱动盈利改善
- **乐观情景**：客户留存率高 + ARPU 提升 + 市场扩张
- **基准情景**：增速自然回落至行业均值
- **悲观情景**：竞争加剧导致价格战 + 大客户流失

### 硬件/制造（华勤技术、富士康类）
- **特点**：薄利多销，资本密集，客户集中度高
- **乐观情景**：新客户导入 + 产品结构升级（高毛利产品占比提升）
- **基准情景**：稳定增长，毛利维持
- **悲观情景**：大客户订单转移 + 原材料涨价侵蚀利润

### AI 基础设施（英伟达、胜宏科技类）
- **特点**：强周期性，Capex 驱动，技术迭代快
- **乐观情景**：AI 投资持续加码 + 算力需求爆发
- **基准情景**：行业进入稳定增长期
- **悲观情景**：AI 泡沫破裂 + Capex 大幅削减

### 生物医药
- **特点**：研发驱动，现金流高度不确定（管线依赖）
- **注意**：DCF 对管线期公司适用性有限，更适合已商业化公司
- **乐观情景**：核心产品放量 + 新适应症获批
- **基准情景**：现有产品稳定增长
- **悲观情景**：专利悬崖 + 竞品冲击

### 新能源汽车（比亚迪、蔚来类）
- **特点**：渗透率提升阶段，Capex 重，价格战频繁
- **乐观情景**：市场份额持续扩大 + 盈利拐点确认
- **基准情景**：增速随渗透率放缓
- **悲观情景**：价格战持续 + 利润率恶化

### 互联网平台（腾讯、美团类）
- **特点**：流量红利见顶，从增长转向利润释放
- **乐观情景**：新业务放量 + 成本优化持续
- **基准情景**：核心业务稳定 + 利润率维持
- **悲观情景**：监管收紧 + 竞争加剧

### 金融/银行
- **特点**：利率敏感，资产质量是核心
- **注意**：银行 DCF 需额外考虑信贷成本和拨备
- **乐观情景**：息差改善 + 资产质量好转
- **基准情景**：稳中向好
- **悲观情景**：坏账暴露 + 息差收窄

## WACC 计算参考

### 无风险利率
- **中国**：10 年期国债收益率（约 1.7-2.0%）
- **美国**：10 年期国债收益率（约 4.0-4.5%）

### 股权风险溢价（ERP）
- **中国市场**（A股/港股）：6-7%
- **美国市场**：5-6%

### Beta
- 防御性行业（消费、公用事业）：0.7-0.9
- 周期性行业（制造、汽车）：1.0-1.3
- 高成长行业（科技、生物医药）：1.1-1.6

### 计算公式
```
权益成本 = Rf + Beta × ERP
WACC（无杠杆）= 权益成本（净现金公司）
WACC（有杠杆）= 权益成本 × E/(E+D) + 债务成本 × D/(E+D) × (1-T)
```
