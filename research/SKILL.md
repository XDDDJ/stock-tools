# 投资研究分析

结构化的投资标的研究工作流，从数据采集到深度分析报告。

## 触发时机

当用户要求研究某个投资标的或市场主题时：
- "研究一下XX公司"、"XX股票怎么样"
- "查一下XX的财报"、"看看这个港股"
- "XX值得投吗"、"分析一下XX的投资价值"
- "帮我做一下XX的调研"

## 数据源优先级

### 第一优先：neodata-financial-search skill
- 覆盖 A股/港股/美股、基金、指数、宏观、外汇、大宗商品
- 支持自然语言提问，实时数据，即问即答
- **默认使用此 skill 查询所有金融数据**

### 第二优先：finance-data-retrieval skill
当 neodata 数据不够详细或字段不足时补充：
- 需要历史数据、批量数据
- 需要精确的结构化查询（209个API接口）
- 财务报表（利润表/资产负债表/现金流量表）

### 第三优先：WebSearch
当前两个 skill 都无法满足时：
- 公司背景/业务模式/行业竞争格局
- 最新新闻/事件/管理层变动
- 明确告知用户数据来源及非实时性

## 研究框架

### 第1步：基本面摸底

通过 neodata/finance-data 获取：
- 公司基本信息（行业/市值/上市时间）
- 最新财务数据（营收/利润/增长率）
- 估值指标（PE/PB/PS/市值）
- 近期股价走势

### 第2步：行业定位

通过 WebSearch 补充：
- 行业赛道规模与增速
- 竞争格局（CR3/CR5/主要竞品）
- 公司核心壁垒/护城河
- 产业链位置（上游/中游/下游）

### 第3步：投资信号评估

#### 正面信号
| 信号类型 | 具体指标 |
|---------|---------|
| 成长性 | 营收/利润连续3年增长，CAGR > 20% |
| 估值合理 | PE < 行业中位数，PS < 10x |
| 技术壁垒 | 核心专利/独特技术路线 |
| 产业趋势 | 所在赛道处于上升期 |
| 资本认可 | 机构持仓上升/北向资金流入 |

#### 风险信号
| 信号类型 | 具体指标 |
|---------|---------|
| 极端偏离 | 涨幅 > 300% 且 PS > 50x |
| 概念炒作 | "XX第一股"称号但核心收入 < 10% |
| 财务异常 | 应收账款暴增/现金流持续为负 |
| 管理风险 | 大股东减持/频繁变更 |
| 政策风险 | 行业监管收紧/补贴退坡 |

### 第4步：极端偏离检测（Boss专属方法论）

针对港股/科创板等高波动标的，检查黑天鹅前兆信号：

**监控条件**（满足任一即标记）：
- 年内涨幅 > 300%
- PS（市销率）> 50x 且未稳定盈利
- 被赋予"XX第一股"称号但核心收入占比 < 10%

**黑天鹅触发信号**（出现即预警）：
- 放量滞涨（成交放大但股价横盘）
- 利好不涨（重大利好公告后股价不涨）
- 大股东减持（尤其是解禁期）
- 孤立上涨后补跌（同板块下跌时独涨）

**历史案例参考**：
- 迅策科技 03317.HK："词元第一股"，年内+470%，PS约70x，Token收入仅占5%

## 沟通原则

- **不做买卖建议**，只做信息整理和风险提示
- **不确定的东西直说**，不编造数据
- **反问补充**：如果用户给的标的不熟悉，主动问"你关注这个标的主要因为什么？"
- **区分事实和观点**：数据是事实，分析是观点，要明确标注

## 踩坑经验

- 港股代码必须带交易所后缀（03317.HK）
- A股代码带后缀（000001.SZ / 600519.SH）
- 财报数据有延迟，注意数据的报告期
- 小盘股流动性差，估值指标参考价值有限
